# 📁 Python File I/O & Log Operations Toolkit

A modular Python script featuring essential file handling utilities, string replacement mechanisms, and line-by-line log analysis algorithms.

## 🎯 Included Functions
- **Transaction & Receipt Logging:** Handles basic data writing to local text files.
- **In-File Text Replacer:** Replaces target terms within a file dynamically.
- **Line-by-Line Keyword Search:** Scans files line-by-line and returns line numbers for matched strings (useful for analyzing log files).
- **Daily Log Writer:** Appends structured entries with separators.
